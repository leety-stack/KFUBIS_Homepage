# 한방유비스 대표홈페이지 개편 — 방향 시안

B2B·B2G(대기업·공공기관) 대응을 위한 한방유비스 대표홈페이지 개편 시안입니다.
반응형(PC·태블릿·모바일), 국문/영문, 공통 관리자(CMS)를 포함합니다.

## 보는 방법

`시안/index.html`을 브라우저로 열면 시안 4종과 관리자 화면을 기기 목업으로 비교해 볼 수 있습니다.

| 파일 | 내용 |
|---|---|
| `시안/A_기업정통형.html` | 전체 화면 사진 + 큰 영문 타이포, 사업분야 바로가기 |
| `시안/B_프로젝트형.html` | 흰 바탕, 실적 목록 중심 (줄을 누르면 사례 펼침) |
| `시안/C_다크프리미엄형.html` | 어두운 바탕, 슬라이드별 큰 영문 단어, 가로 사례 카드 |
| `시안/D_화이트모던형.html` | 흰 바탕 + 영문 타이포·사진 겹침, 사업분야·발주처 탭 |
| `시안/관리자.html` | 공통 관리자 23개 화면 (대시보드, 메인 구성, 배너, 메뉴, 페이지 편집, 팝업, 게시판 6종, 접수함 3종, 설정 5종, 관리자 3종) — 페이지 편집·검색 노출·접속 통계·변경 이력은 "옵션" 표시, 숨기려면 `admin-views.js`의 HIDDEN에 넣기 |
| 첫 화면 계열사 선택 | 시안 A~D 공통 `시안/gate.js` — 들어오면 한방·한방유비스·케이유비스·AI 계열사 중 선택, 한방유비스는 바로 메인. 하단 Family Site도 함께. `?gate=1` 다시 보기, `?gate=0` 끄기 |

각 시안 주소 끝에 `?lang=en`을 붙이면 영문으로 열립니다.

## 공통 원칙

- B2B 요소: 3초 가치 제안, 숫자·발주처 신뢰 지표, 사례(과제·수행·결과), 발주처 유형별 안내, 필수 3칸 간편 문의
- 관리자: 오픈 후 글·사진·메뉴·팝업·계정을 담당자가 직접 고쳐 개발자 작업이 필요 없게 설계
- 애니메이션: `시안/motion.js` 공통 사용, 사용자의 "동작 줄이기" 설정을 따름

## 참고

- 사진·로고는 현재 홈페이지(kfubis.co.kr) 자산이며 사진과 실적 이름의 짝은 확인 전입니다.
- 게시판 글·날짜, 관리자 화면의 숫자는 화면 구성을 보여 주기 위한 예시입니다.

## 개발 (관리자) — 1단계

| 폴더 | 내용 |
|---|---|
| `server/` | PocketBase 0.39.4 — `pb_migrations/`(데이터 구조·권한 규칙·초기 데이터), `pb_hooks/`, Dockerfile |
| `admin/` | 관리자 화면 — React + Vite + TypeScript, 개발 포트 5183 |

**로컬 실행**
```bash
# 1) PocketBase (8095) — 윈도우 실행 파일은 server/bin/ 에 직접 받기 (저장소에 안 올림)
cd server && ./bin/pocketbase.exe serve --http=127.0.0.1:8095 --dir pb_data --migrationsDir pb_migrations --hooksDir pb_hooks
# 2) 관리자 화면 (5183, /api 는 8095로 넘김)
cd admin && npm install && npm run dev
```
- 개발용 첫 계정: `admin@kfubis.local` / `kfubis-dev-1234` (운영은 `.env`의 `CMS_ADMIN_EMAIL`·`CMS_ADMIN_PASSWORD`로 처음 한 번 생성 — 반드시 바꿀 것)
- 권한은 서버에서도 확인: 역할(`roles.perms`)의 메뉴별 단계 0 없음 · 1 보기 · 2 수정(임시저장까지) · 3 게시. 최고 관리자는 전부.
- 점검: `py -3.10 server/tests/perm_test.py`(서버 권한 23개), `py -3.10 admin/tests/ui_test.py`(1단계 화면 13개), `py -3.10 admin/tests/ui_test2.py`(2단계 화면 24개)

**동작하는 것**
- 1단계: 로그인, 대시보드, 게시판 6종(실적·소식·R&D·인증·자료실·채용 — 목록·필터·검색·노출 스위치·편집 팝업·국문/영문·사진·첨부·달력·예약 게시)
- 2단계: 메뉴 관리(2단 구조·끌어서 순서·노출·연결할 곳), 메인 배너(PC·모바일 사진·국/영문·기간·순서·미리보기), 팝업(기간·위치 9칸·크기·기기·페이지·닫기 옵션·미리보기), 메인 화면 구성(첫 화면 계열사 선택 회사 목록, 영역 순서·노출·설정)
- 나머지 메뉴는 "준비" 표시. 초기 배너·팝업 사진은 `server/pb_seed/`
**운영 배포:** `docker compose up -d --build` (PocketBase), `admin/` 은 `npm run build` 결과를 웹서버에 올리고 `/api` 를 PocketBase로 넘김.
