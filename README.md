# 한방유비스 대표홈페이지 개편 — 방향 시안

B2B·B2G(대기업·공공기관) 대응을 위한 한방유비스 대표홈페이지 개편 시안입니다.
반응형(PC·태블릿·모바일), 국문/영문, 공통 관리자(CMS)를 포함합니다.

## 보는 방법

`시안/index.html`을 브라우저로 열면 시안 4종과 관리자 화면을 기기 목업으로 비교해 볼 수 있습니다.

| 파일 | 내용 |
|---|---|
| `시안/A_기업정통형.html` | 전체 화면 사진 + 큰 영문 타이포, 사업분야 바로가기 |
| `시안/B_프로젝트형.html` | 흰 바탕, 실적 목록 중심 (줄을 누르면 사례 펼침) |
| `시안/C_다크프리미엄형.html` | 어두운 바탕, 슬라이드별 큰 영문 단어, 가로 사례 카드 |
| `시안/D_화이트모던형.html` | 흰 바탕 + 영문 타이포·사진 겹침, 사업분야·발주처 탭 |
| `시안/관리자.html` | 공통 관리자 19개 화면 (대시보드, 메인 구성, 배너, 메뉴, 팝업, 게시판 6종, 접수함 3종, 설정 2종, 관리자 3종) — 페이지 편집·검색 노출·접속 통계·변경 이력은 코드에 있으나 숨김(`admin-views.js`의 HIDDEN) |

각 시안 주소 끝에 `?lang=en`을 붙이면 영문으로 열립니다.

## 공통 원칙

- B2B 요소: 3초 가치 제안, 숫자·발주처 신뢰 지표, 사례(과제·수행·결과), 발주처 유형별 안내, 필수 3칸 간편 문의
- 관리자: 오픈 후 글·사진·메뉴·팝업·계정을 담당자가 직접 고쳐 개발자 작업이 필요 없게 설계
- 애니메이션: `시안/motion.js` 공통 사용, 사용자의 "동작 줄이기" 설정을 따름

## 참고

- 사진·로고는 현재 홈페이지(kfubis.co.kr) 자산이며 사진과 실적 이름의 짝은 확인 전입니다.
- 게시판 글·날짜, 관리자 화면의 숫자는 화면 구성을 보여 주기 위한 예시입니다.
